# request_keeper

CLI-клиент для отправки запросов по протоколам REST, SOAP и gRPC с сохранением ответов в локальную базу данных. Проект обеспечивает единый интерфейс для работы с разными типами API и предоставляет функционал для извлечения сохранённых ответов по уникальному идентификатору.

Логика работы построена на определении типа протокола по URL: клиент автоматически распознаёт REST (обычный URL), SOAP (URL с `?wsdl`) и gRPC (URL с префиксом `grpc://`). Для каждого протокола используется соответствующая библиотека — `requests`, `zeep` и `grpcio`. После получения ответа он выводится в консоль и сохраняется в базу данных SQLite с присвоением уникального ID. Пользователь может впоследствии извлечь сохранённый ответ командой **--get**, указав его ID. Для gRPC-запросов поддерживается динамическая загрузка `.proto` файла по ссылке с автоматической генерацией Python-кода.

Для запуска необходимы Python 3.6+ и установленные зависимости. База данных (requests.db) создаётся автоматически при первом запуске. Для gRPC-запросов требуется указать URL к `.proto` файлу через аргумент **--proto**.

Python 3.6: **argparse** , **requests** , **zeep** , **grpcio** , **grpcio-tools** , **sqlite3**
